# Super-Mario-Qt

Учебный проект на C++ и Qt. Цель — перенести консольный платформер в оконное приложение со спрайтами, сохранив правила движения, прыжков и столкновений.

## План Qt-версии

- **Первый этап** — запустить один уровень в окне Qt, отрисовать игровые объекты спрайтами и подключить управление с клавиатуры.
- **После запуска уровня** — добавить главное меню с кнопками «Играть», «Выбрать уровень», «Настройки» и «Выход». Настройки сложности будут влиять на скорость врагов.

## Архитектура

Планируется сохранить разделение игровой логики и интерфейса. Игровая логика отвечает за состояние уровня, персонажей и столкновения. Интерфейс Qt обрабатывает ввод и отрисовывает состояние игры. Например, команда прыжка поступает из интерфейса, а возможность её выполнить определяют правила игры.

## Сборка и запуск

Инструкция по сборке и список клавиш появятся после проверки первого запуска Qt-версии из чистого клона.
